# RE-Forecast Lite

전국 태양광·풍력 시간별 발전량을 기상 예보로 예측하는 AI 툴입니다. 예측 시작일 직전 3년만으로 학습하고, 예측이 끝난 뒤에 실측과 비교합니다.

## 실행

```bash
pip install lightgbm scikit-learn scipy pandas numpy openpyxl
python re_forecast_tool.py --data-dir ./data --start 2026-10-17 --end 2026-10-23 --train-years 3 --out ./outputs
```

`--data-dir`에는 아래 파일을 넣습니다. 파일명 일부만 맞으면 됩니다.

| 파일 패턴 | 내용 | 용도 |
|---|---|---|
| `*5min*.csv` | KPX 발전원별 발전현황 5분(전국 `sunlight`, `windPower`) | 예측 대상(정답). 시간평균으로 집계 |
| `*kpx*.csv` (5min 제외) | KPX 지역별 시간별 태양광·풍력 | 태양광 지역 가중치, 풍력 5분값 이전 구간 보충 |
| `*openmeteo*.json.gz` | Open-Meteo 번들 (`archive`, `prev`, `single`) | 기상 입력 |

## 흐름

1. **정답값**: 5분 실측을 시간평균(MWh)으로 묶습니다. 공급 전 `0` 구간, 중복 행, 음수 태양광을 정리합니다. 풍력 5분값이 없는 기간은 KPX 시간별 풍력에 겹침 기간 비율을 곱해 채웁니다.
2. **입력**: 태양광은 22개 지점의 일사·직달·산란·운량·기온·습도·강수·풍속과 태양고도·맑은 날 일사량·계절·시각을 씁니다. 풍력은 7개 단지의 100m 풍속·풍향(u, v), 10m 풍속, 시어, 기온, 기압, 출력곡선, 기압차를 씁니다. 과거 예보에 없는 변수(하층운량, 적설, 돌풍)는 학습에서도 뺍니다.
3. **설비 증가 반영**: 실측을 '최근 실측 ÷ 기상 잠재량' 비율로 나눠 학습합니다. 비율 창은 태양광 60일, 풍력 180일입니다. 예측 때는 예측 직전 비율을 곱합니다.
4. **모델**: LightGBM(점예측, P10, P90)과 MLP 신경망을 씁니다.
5. **사전 검증**: 학습 마지막 약 60일을 떼어 둡니다. 그 당시 실제로 발표된 예보(`prev` D-1·D-2)로 예측해 보고 다음 네 가지를 정합니다.
   - 예보모델 가중
   - GBM/MLP 가중
   - 수준 보정
   - P10~P90 폭 (CQR)
6. **최종 예측**: 3년 전체로 다시 학습한 뒤 예측합니다.
   - **주간 일괄**: `single` 발표 예보 하나로 7일을 예측합니다. 발표 전 시간은 D-1 예보로 채웁니다.
   - **D-1 롤링**: 매일 전날 예보로 그날을 예측합니다.
7. **비교**: 예측 저장 후에야 예측기간 실측을 읽습니다. 지표는 MAE, RMSE, MBE, nMAE, KPX 오차율, R², 총량오차, 구간 적중률입니다. 전일 지속, 7일 평균 같은 기준 예측과도 비교합니다. 관측기상 사후예측은 기상예보 오차와 모델 오차를 나눠 보기 위한 참고용입니다.

## 정보 차단 (누설 방지)

- 학습·검증에 쓰는 발전 실측과 재분석 기상은 예측 시작일 0시 이전 값만 씁니다.
- 예측 입력은 발표된 예보(`single`, `prev`)만 씁니다.
- 예측기간 실측과 관측기상은 예측값이 확정된 뒤에만 읽습니다.

## 출력

- `RE_forecast_<기간>.xlsx`: 요약, 발전원별 지표, 일별·시간별 결과, 사전검증, 피처중요도, 사용데이터
- `RE_forecast_<기간>.json`: 리포트·대시보드용 데이터
