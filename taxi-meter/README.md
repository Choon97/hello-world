# 장난 택시미터 (안드로이드 오토)

친구 태워줄 때 차 화면에 택시 미터기를 띄우는 장난용 앱이에요. 실제 요금을 받는 용도가 아니에요.

- 안드로이드 오토 차 화면에 미터기를 그려요. 내비게이션 종류 앱으로 등록해서 화면을 직접 그려요.
- 폰에서도 같은 미터기를 볼 수 있어요.
- 폰 GPS로 거리를 재고, 시속 15km 이하에서는 시간요금이 올라가요.
- 시외 할증 버튼이 있고, 심야 할증은 시간에 따라 자동으로 붙어요.
- 운행을 종료하면 영수증이 나와요.

## 기본 요금 (나주시 택시운임표)

| 항목 | 값 |
|---|---|
| 기본운임 | 2km까지 4,300원 |
| 거리운임 | 130m당 140원 |
| 시간운임 | 15km/h 이하, 30초당 140원 |
| 심야 할증 | 00:00~04:00, 20% |
| 시계 외 할증 | 35% |
| 심야 + 시계 외 | 40% (운임표에 없는 값이라 임시로 넣음, 설정에서 변경 가능) |

모든 값은 폰 앱의 **요금 설정**에서 바꿀 수 있어요.

## 설치

1. GitHub 저장소의 **Actions** 탭 → **Build taxi meter APK** → 가장 최근 실행 → 아래 **Artifacts**에서 `taxi-meter-apk`를 받아요. zip 파일 안에 `app-debug.apk`가 있어요.
2. 폰에서 APK를 설치해요. "출처를 알 수 없는 앱 설치"를 허용해야 해요.
3. 앱을 한 번 열어서 **위치 권한**과 **알림 권한**을 허용해요.
4. 안드로이드 오토 설정에서 개발자 모드를 켜요.
   - 폰 설정 → 연결된 기기 → 연결 환경설정 → Android Auto로 들어가요.
   - 맨 아래 **버전**을 10번 눌러요.
   - 오른쪽 위 ⋮ → **개발자 설정** → **알 수 없는 출처**를 체크해요.
5. 차에 연결한 뒤 안드로이드 오토 앱 목록에서 **장난 택시미터**를 열어요.

> 빌드할 때마다 서명 키가 새로 만들어져요. 새 버전을 설치하기 전에 기존 앱을 지워야 할 수 있어요.

## 차 화면 버튼

- **운행 시작 / 운행 종료 / 빈차**: 미터기 상태를 바꿔요.
- **시외 ON/OFF**: 시계 외 할증을 켜고 꺼요.
